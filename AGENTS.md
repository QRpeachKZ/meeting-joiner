# AGENTS.md - Meeting Joiner

Краткие инструкции для агента при работе с этим проектом.

## Обзор проекта
- **Тип**: нативное macOS-меню-бар-приложение (MVP)
- **Назначение**: синхронизирует встречи из Google Calendar и on-prem Microsoft Exchange (EWS), напоминания о старте встреч. Автоматический вход в конференцию не происходит - открытие ссылки по кнопке "Connect" только после выбора пользователя.
- **Платформа**: macOS 13+, Swift 5.9
- **Структура**: Swift Package с двумя таргетами (Core + App) и тестами

## Структура репозитория
```
Sources/
  MeetingJoinerCore/      # Бизнес-логика: провайдеры календарей, синхронизация, напоминания
  MeetingJoinerApp/       # macOS UI/menu bar, авторизация, Keychain, настройки
  MeetingJoinerCoreTests/ # Unit-тесты
scripts/
  build-app.sh            # Сборка .app бандла
Package.swift
README.md
```

## Архитектура и ключевые модули
- **MeetingCalendarProvider** - интерфейс провайдера календаря. Реализации: `GoogleCalendarProvider` (OAuth + Calendar API), `ExchangeEWSProvider` (EWS SOAP).
- **CalendarSyncService** - объединяет встречи от провайдеров, сортирует, кэширует. При успешном обновлении провайдера кэш этого провайдера полностью перезаписывается (включая пустой результат). При ошибке кэш провайдера сохраняется.
- **ReminderCoordinator** - дедупликация напоминаний о старте, трекинг "Skip", открытие ссылок через инжектируемый opener. Только UI/notification action-обработчик может открывать распознанную конференц-ссылку по "Connect".
- **ConferenceURLRecognizer** - распознавание ссылок (Google Meet, Zoom, MS Teams, Webex, Whereby, BlueJeans).
- **Ключевые места хранения**: токены/пароли/сертификаты в **macOS Keychain**. Неконфиденциальные настройки - в UserDefaults. Локальный `client_secret*.json` в корне проекта игнорируется git (не логируется/не показывается в UI).

Скрипт сборки создает unsigned `.app` для локального тестирования. Сборка через Xcode тоже должна работать.

## Правила работы с проектом
### Конфигурация и секреты
- **Никогда** не коммить секреты: OAuth client secrets, Exchange пароли, refresh/access токены, приватные ключи. Они должны храниться только в Keychain.
- `client_secret_*.json` уже в .gitignore - не трогать/не добавлять содержимое в трек.
- При изменениях в коде, который работает с конфигурацией/секретами, учитывать валидацию и что несохраненные правки не влияют на синхронизацию.
- Exchange: только Basic auth в MVP, TLS по умолчанию обязателен. "No-TLS" режим - явный, с предупреждением, убирает пароль, без Authorization заголовка.

### Провайдеры и синхронизация
- `MeetingCalendarProvider` - единая граница. Добавление нового провайдера должно реализовывать этот протокол и интегрироваться через `CalendarSyncService`.
- Каждый провайдер при успехе перезаписывает только свой кэш. Ошибки провайдера не должны затирать существующий валидный кэш.
- Exchange: батчинг `FindItem` + `GetItem`, без пагинации (truncated ответ -> явная ошибка). Google: использовать expanded events (учитывать all-day/recurring).
- Диапазон выборки ограничен (см. реализацию) - не менять произвольно без обоснования.

### Напоминания и UI
- Напоминания проверяются независимо от синхронизации (каждую секунду/после сна). Завершённые встречи не анонсируются.
- Дедупликация напоминаний, учёт "Skip" - логика в `ReminderCoordinator`. Открытие ссылки - только через action обработчик уведомления/UI ("Connect").
- Распознавание конференц-ссылок централизовано в `ConferenceURLRecognizer` - при добавлении хостов править только там.
- macOS notification permission обязателен для напоминаний о старте.

### Тесты
- Есть unit-тесты в `MeetingJoinerCoreTests/` (конфигурация, слияние синхронизации, распознавание ссылок, действия напоминаний). При изменении соответствующей логики - обновлять/добавлять тесты.
- `swift test` должен проходить.

## Стиль кода
- Следовать существующему стилю проекта (Swift, читаемый код, минимальные зависимости). В Package.swift нет внешних зависимостей.
- Сохранять инкапсуляцию: Core не должен зависеть от UI-специфичных деталей App; зависимости направлены через зависимости таргетов.
- Обработка ошибок явная, валидация настроек до сохранения.

## Важные ограничения (не реализовывать)
- Microsoft Graph, Windows/Linux
- Автоматический вход в конференцию
- Подписанный/установочный инсталлятор
- Windows Integrated auth (NTLM/Kerberos) для Exchange
- Отключение/обход валидации сертификатов
- Пагинация Exchange (пока MVP-ограничение)
